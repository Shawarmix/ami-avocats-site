# AMI Avocats — Site internet

Prototypes HTML / CSS / JS du site du cabinet AMI Avocats.

## Structure

- `prototype clair.html`, `prototype foncé.html` — versions claire et sombre du prototype principal
- `miami *.html` — variantes de design (white, purple, animation, HDR)
- `Encre dense 1.html`, `Dragon.html`, `index 2.html` — itérations supplémentaires
- `assets/` — logos, images, composants JSX (hero, sections, themes, tweaks…)
- `docs/superpowers/` — specs et plans d'implémentation

## Vidéos

Seule `assets/MAYBE THE ONE.mov` est versionnée. Les autres fichiers vidéo (`.mp4`, `.mov`) sont **exclus du dépôt** via `.gitignore` pour rester sous la limite GitHub de 100 Mo par fichier — ils restent en local dans `assets/`.

## Visualiser

Ouvrir n'importe quel fichier `.html` directement dans un navigateur — pas de build nécessaire.
